# 📱 Guia: Como Compartilhar Artigos no Instagram

## 🎨 Sistema de Geração de Cards para Instagram

Criamos um sistema completo que permite gerar cards visuais otimizados para Instagram diretamente dos artigos do blog!

## ✨ Funcionalidades

### 1. **Geração de Cards Visuais**
- ✅ Cards otimizados para Instagram Feed (1080x1080px - formato quadrado)
- ✅ Cards otimizados para Instagram Stories (1080x1920px - formato vertical)
- ✅ Design profissional com gradientes e tipografia moderna
- ✅ Inclui título, resumo, categoria, autor e branding

### 2. **Como Usar**

#### Passo 1: Acesse um Artigo
1. Vá para `/blog`
2. Clique em qualquer artigo para abrir

#### Passo 2: Gere o Card
1. Role até a seção "Compartilhe este artigo"
2. Você verá um box destacado com duas opções:
   - **Feed (1:1)** - Para posts no feed do Instagram
   - **Stories (9:16)** - Para stories do Instagram

#### Passo 3: Baixe a Imagem
1. Clique no botão desejado (Feed ou Stories)
2. Aguarde alguns segundos enquanto a imagem é gerada
3. A imagem será baixada automaticamente no seu computador
4. O nome do arquivo será algo como: `instagram-feed-titulo-do-artigo.png`

#### Passo 4: Compartilhe no Instagram
1. Abra o Instagram (app ou web)
2. Crie um novo post ou story
3. Selecione a imagem baixada
4. Adicione hashtags relevantes (veja sugestões abaixo)
5. Adicione o link do artigo na bio ou use o link nos stories
6. Publique!

## 📝 Dicas para Compartilhar no Instagram

### 1. **Legenda do Post**
Use uma legenda envolvente que:
- Comece com uma pergunta ou afirmação impactante
- Mencione o tema do artigo
- Convide para ler mais
- Inclua um CTA claro (ex: "Link na bio" ou "Swipe up" nos stories)

**Exemplo de legenda:**
```
Você já se sentiu perdido, sem saber qual o sentido da vida? 🤔

A Logoterapia, criada por Viktor Frankl, pode ajudar você a encontrar propósito mesmo nos momentos mais difíceis.

No artigo de hoje, explico como essa abordagem terapêutica funciona e como ela pode transformar sua vida.

👉 Link na bio para ler o artigo completo!

#logoterapia #viktorfrankl #psicologiagoiania #terapiaonline #saudemental
```

### 2. **Stories do Instagram**
- Use o card gerado como imagem principal
- Adicione stickers (perguntas, enquetes, links)
- Use o sticker de link (se tiver mais de 10k seguidores) ou mencione "Link na bio"
- Adicione texto complementar se necessário

### 3. **Feed do Instagram**
- Use o card gerado como imagem principal
- Adicione até 10 imagens adicionais se quiser (exemplos, citações, etc.)
- Use a legenda completa com hashtags
- Responda comentários para aumentar engajamento

## 🔧 Solução de Problemas

### A imagem não está sendo gerada:
1. Verifique se a imagem do artigo está acessível
2. Tente novamente após alguns segundos
3. Certifique-se de que não há bloqueadores de pop-up

### A imagem está com qualidade baixa:
- As imagens são geradas em alta qualidade (2x scale)
- Se necessário, você pode editar a imagem em um editor antes de postar

### O texto está cortado:
- Os cards são otimizados para os tamanhos padrão do Instagram
- Se o título for muito longo, considere criar uma versão mais curta manualmente
