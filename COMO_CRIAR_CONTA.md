# Como Criar sua Conta Administrativa

## 🎯 Passo a Passo para Criar sua Primeira Conta

### 1. Acesse a Página de Registro

Vá para: **`/admin/register`**

Ou acesse: `http://localhost:5173/admin/register` (em desenvolvimento)
Ou: `https://seu-site.com/admin/register` (em produção)

### 2. Preencha os Dados

- **E-mail**: Use um email válido (será seu login)
- **Senha**: Mínimo de 6 caracteres
- **Confirmar Senha**: Digite a mesma senha novamente

### 3. Clique em "Criar Conta"

Após criar a conta, você será redirecionado automaticamente para a área administrativa.

### 4. Próximos Passos

Depois de criar a conta, você pode:

1. **Publicar os artigos do blog:**
   - Acesse `/admin/criar-artigos`
   - Clique em "Criar 5 Artigos"
   - Os artigos serão adicionados automaticamente

2. **Gerenciar o blog:**
   - Acesse `/admin/blog`
   - Crie, edite ou exclua posts
   - Gerencie todo o conteúdo do blog

## 🔐 Segurança

- **Guarde suas credenciais com segurança**
- Use uma senha forte (recomendado: 8+ caracteres com letras, números e símbolos)
- Não compartilhe suas credenciais

## ❓ Problemas Comuns

### "Este email já está em uso"
- Significa que já existe uma conta com esse email
- Tente fazer login em vez de criar nova conta
- Ou use outro email

### "A senha deve ter pelo menos 6 caracteres"
- Use uma senha com no mínimo 6 caracteres
- Recomendado: 8 ou mais caracteres para maior segurança

### Não consigo acessar após criar a conta
- Verifique se o Firebase Authentication está configurado corretamente
- Verifique se o email foi verificado (se necessário)
- Tente fazer logout e login novamente

## 📝 Nota Importante

Esta é a primeira conta criada e terá acesso total à área administrativa. Use com responsabilidade!
