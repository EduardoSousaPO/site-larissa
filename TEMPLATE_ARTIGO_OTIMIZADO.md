# 📝 Template de Artigo Otimizado

Use este template como base para criar ou melhorar artigos seguindo as melhores práticas.

## Estrutura Completa

```html

<ul>
  <li><strong>[Item importante]</strong>: [Descrição]</li>
  <li><strong>[Item importante]</strong>: [Descrição]</li>
  <li><strong>[Item importante]</strong>: [Descrição]</li>
</ul>

<p><strong>Verdade:</strong> [Esclarecimento - 2-3 parágrafos]</p>

<p>Você deve considerar buscar ajuda profissional se:</p>
<ul>
  <li>[Sinal 1 - descrição]</li>
  <li>[Sinal 2 - descrição]</li>

<!-- CTA FINAL DESTACADO -->

  <h3 style="color: #5b21b6; margin-top: 0; margin-bottom: 1rem; font-size: 1.5rem;">Você não precisa enfrentar isso sozinho</h3>
  <p style="color: #6d28d9; margin-bottom: 1.5rem; font-size: 1.125rem;">[Mensagem personalizada sobre o tema]</p>
  <p style="color: #6d28d9; margin-bottom: 1.5rem;">[Mais informações sobre como a terapia pode ajudar]</p>

</div>
```

## 📋 Checklist de Aplicação

Ao usar este template, certifique-se de:

- [ ] **Hook forte** nos primeiros 2-3 parágrafos
- [ ] **Parágrafos curtos** (2-4 frases, máximo 100 palavras)
- [ ] **H2 a cada 300-400 palavras**
- [ ] **H3 para subseções** dentro de cada H2
- [ ] **Listas** quando houver 3+ itens relacionados
- [ ] **Boxes destacados** para informações importantes
- [ ] **Perguntas estratégicas** ao longo do texto
- [ ] **Exemplos práticos** em cada seção principal
- [ ] **Links internos** (3-5 links para outros artigos)
- [ ] **CTA intermediário** após seção importante
- [ ] **CTA final** destacado e claro
- [ ] **Total de 1.800-2.500 palavras**

## 🎨 Cores para Boxes

- **Informação geral:** `#f3f4f6` (cinza claro)
- **Dica importante:** `#fef3c7` (amarelo claro)
- **Atenção/aviso:** `#fee2e2` (vermelho claro)
- **CTA principal:** `#ede9fe` (roxo claro)
- **Sucesso/positivo:** `#d1fae5` (verde claro)

## 📊 Exemplo de Distribuição de Palavras

Para um artigo de 2.000 palavras:

- Introdução: 150 palavras (7.5%)
- Seção 1 (Problema): 450 palavras (22.5%)
- Seção 2 (Solução): 550 palavras (27.5%)
- Seção 3 (Prática): 450 palavras (22.5%)
- Seção 4 (Mitos): 200 palavras (10%)
- Seção 5 (Ajuda): 100 palavras (5%)
- Conclusão + CTA: 100 palavras (5%)
